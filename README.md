# EarthSage-AI
An interactive planetary sustainability intelligence platform for climate risk analysis, water security, air quality monitoring, food-system exposure and clean-energy insights using environmental data analytics.
EarthSage AI – Planetary Sustainability Intelligence

EarthSage AI is an interactive environmental intelligence platform designed to explore climate signals, water security, air quality, food-system exposure and clean-energy opportunities through data analytics and visualization.

Key Features

- Environmental overview dashboard
- Seven-day weather and climate indicators
- Global earthquake event monitoring
- Rainfall and soil-moisture analysis
- Air quality and pollutant visualization
- Agricultural climate-exposure indicators
- Solar radiation and clean-energy analysis
- CSV upload and dataset preview
- Environmental data export
- Shareable environmental snapshots

Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Open-Meteo APIs
- USGS Earthquake GeoJSON Feed

How to Run

1. Download or clone this repository.
2. Open "index.html" in a modern web browser.
3. Ensure an internet connection is available.
4. Search for a city to load environmental data.
5. Explore the six intelligence modules.

Data Sources

- Open-Meteo Weather Forecast API
- Open-Meteo Air Quality API
- USGS Earthquake Hazards Program

Data Science Concepts Demonstrated

- Environmental data collection
- Data exploration and visualization
- Time-series analysis
- Feature interpretation
- Risk-indicator development
- Data quality and provenance
- Transparent, rule-based analytical insights

Important Limitations

This is an educational and portfolio prototype. Forecasts are model outputs, not guaranteed observations. Water and food indicators are screening proxies, not validated predictions. Solar radiation is not electricity generation. Earthquake events are historical observations, not earthquake predictions.

The platform is not a substitute for official environmental, medical or emergency guidance.
